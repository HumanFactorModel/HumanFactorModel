## 本卷简介

本书是《中华鉴心心感自主知识体系》的第三卷，名为"鉴心人伦"。本卷将第一、二卷修得的内圣功夫延伸至家庭领域，先确立"家庭心感场"这一无形能量空间的运作规律，再逐一分析父子、夫妇、兄弟、朋友、君臣五伦关系中的感位对接与错位，进而深入探讨教养的本质——大人自身的心脉状态如何作为"土壤"无声地代际传递，最终揭示家风是家族心感场的纵向延伸、家运是家风的自然果报，完成从"一个人的庙"到"一家人的屋檐"的齐家路径。

如果您是第一次接触心感学，建议从[第一卷](../volume-01/README.md)开始阅读。如果您已经了解基础概念，可以直接查阅已开源的 [理论纲要](../../THEORY.md) 和 [术语词典](../../GLOSSARY.md) 作为快速参考。
