## 本卷简介

本书是《中华鉴心心感自主知识体系》的第六卷，名为"鉴心大同"。本卷将视野扩展至人类文明的整体层面，首先剖析文明冲突最深层的根源在于不同文明心感默认值的错位，进而论证十二心脉是全人类共享的普遍感受结构，提出以共同感受地层为基础的心感对话机制，确立人类命运共同体最坚实的心感基石，最终描绘大同世界的心感图景——那不是所有文明趋同为一，而是所有文明都能在保持各自特色的同时，在感受深层认出彼此是同类，实现从文明冲突到文明共生的完整论述。

如果您是第一次接触心感学，建议从[第一卷](../volume-01/README.md)开始阅读。如果您已经了解基础概念，可以直接查阅已开源的 [理论纲要](../../THEORY.md) 和 [术语词典](../../GLOSSARY.md) 作为快速参考。
