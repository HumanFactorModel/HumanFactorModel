## 本卷简介

本书是《中华鉴心心感自主知识体系》的第五卷，名为"鉴心为政"。本卷将心感学延伸至社会治理层面，首先提出各个岗位上担当者的心脉要求，继而建构社会心感指数的十二维度框架与自明自证的数据采集原则，展开政策的心感评估方法、心感修复的四种社会支持空间，以及心感法治的框架，最终揭示规则共识并非写在纸上的条文，而是从千千万万条心脉的真实共振中自然生长出来、又在心脉稳定中得到维系的活秩序，完成从微观心感互动到宏观社会秩序的治理路径。

如果您是第一次接触心感学，建议从[第一卷](../volume-01/README.md)开始阅读。如果您已经了解基础概念，可以直接查阅已开源的 [理论纲要](../../THEORY.md) 和 [术语词典](../../GLOSSARY.md) 作为快速参考。
