## 本卷简介

本书是《中华鉴心心感自主知识体系》的第七卷，名为"鉴心器用"。本卷聚焦于心感学的技术实现层面，依次展开心感映射技术如何将日常语言转化为十二心脉感位坐标、心感隐私与主权的分布式保障原则、支撑从个人照见到文明对话的五层心感基础设施架构，最终确立技术向善的四项终极规范——不替代人的判断、不暴露人的隐私、不制造外部依赖、不进行群体比较，确保所有技术工具永远只做一件事：照亮人心，而非替代人心。

如果您是第一次接触心感学，建议从[第一卷](../volume-01/README.md)开始阅读。如果您已经了解基础概念，可以直接查阅已开源的 [理论纲要](../../THEORY.md) 和 [术语词典](../../GLOSSARY.md) 作为快速参考。
