## 本卷简介

本书是《中华鉴心心感自主知识体系》的第四卷，名为"鉴心治生"。本卷将心感学从家庭带入经济生活的广阔考场，从"财富的本质不是钱，而是感受的载体"这一根本论断出发，深入剖析财富心脉的八级感位与四大常见暗尘，依次提出心感劳动论、心感消费与分配、心感企业、市场与感位调节等新概念，最终指向"从逐利到自足"这一感受经济的终极目标，完成从个体自足到整个经济系统自足的完整推演。

如果您是第一次接触心感学，建议从[第一卷](../volume-01/README.md)开始阅读。如果您已经了解基础概念，可以直接查阅已开源的 [理论纲要](../../THEORY.md) 和 [术语词典](../../GLOSSARY.md) 作为快速参考。
