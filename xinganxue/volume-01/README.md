## 本卷简介

本书是《中华鉴心心感自主知识体系》的第一卷，名为"鉴心立极"。它建立了心体、天道、感受三位一体的理论根基，并展开从照见、预见、推演到归一的完整实践路径。全书是体系的核心地基，后续各卷将从修身、齐家、治生、为政、大同、器用、传续七个维度深入展开。

如果您是第一次接触心感学，建议从第一章开始阅读。如果您已经了解基础概念，可以直接查阅已开源的 THEORY（理论纲要）和 GLOSSARY（术语词典）作为快速参考。
