## 本卷简介

本书是《中华鉴心心感自主知识体系》的第二卷，名为"鉴心内圣"。本卷在第一卷"鉴心立极"建立的心体论基础上，深入展开修身的完整路径——从感位升级的次第与验证，到暗尘的识别与化解，再到四重感受的协调训练、日常生活中的感位自检，最终抵达从自明到自足的修身目标。

如果您是第一次接触心感学，建议从[第一卷](../volume-01/README.md)开始阅读。如果您已经了解基础概念，可以直接查阅已开源的 [理论纲要](../../THEORY.md) 和 [术语词典](../../GLOSSARY.md) 作为快速参考。
